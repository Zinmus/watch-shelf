# Project guidelines

This is a Vue 3 + Vite + Tailwind CSS application.

## Code style

- Use Vue Composition API.
- Prefer `<script setup>`.
- Keep components small and focused.
- Do not add dependencies unless they solve a clear problem.
- Do not refactor unrelated code.

## Workflow

- Read relevant code before making changes.
- For larger changes, explain the approach first.
- After changes, run lint and build.
